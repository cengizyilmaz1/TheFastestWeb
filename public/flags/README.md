# Country flags

These 249 ISO 3166-1 alpha-2 flags are served locally as 4:3 SVGs so they
display consistently on Windows, mobile and desktop without a third-party host.
The set matches `src/modules/catalog/countries.ts` and the IndieTools picker.

Source: [flag-icons](https://github.com/lipis/flag-icons), copied from the
IndieTools asset collection. Copyright (c) 2013 Panayiotis Lipiridis.
Distributed under the MIT license; see [LICENSE.txt](./LICENSE.txt).

To update, copy the required `flags/4x3/*.svg` files from flag-icons and retain
the license. Validate every pinned country code has a matching asset before
publishing. Country is explicitly selected by the submitter; it is not inferred
from a visitor's IP address, domain or hosting provider.
